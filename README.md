# 🏋️ FitShow – باشگاه ورزشی فیت‌شو

وب‌سایت رسمی باشگاه فیت‌شو – یک قالب مدرن، سریع و واکنش‌گرا برای باشگاه‌های بدنسازی و فیتنس.

> 🇮🇷 This project is fully in Persian (RTL) with support for English fallback.

---

## ✨ ویژگی‌ها

- **طراحی کاملاً واکنش‌گرا** – مناسب برای موبایل، تبلت و دسکتاپ
- **تم تاریک مدرن** با لهجه قرمز (رنگ اصلی `#f44336`)
- **صفحات جداگانه**:
  - صفحه اصلی (`index.html`) – شامل هیرو، ویژگی‌ها، کلاس‌ها و دعوت به اقدام
  - درباره ما (`about.html`) – تاریخچه، تیم مربیان و ارزش‌ها
  - تماس با ما (`contact.html`) – فرم تماس، اطلاعات تماس و نقشه گوگل
- **فرم‌های کاربردی** (عضویت در خبرنامه، فرم تماس)
- **نقشه تعبیه‌شده** (Google Maps iframe)
- **آیکون‌های Font Awesome** (نسخه ۶)
- **فونت فارسی وزیرمتن** (Vazirmatn)
- **کد تمیز و قابل توسعه** – استفاده از کلاس‌های تکراری برای یکپارچگی

## 🚀 نحوه اجرا و مشاهده

1. **دانلود یا کلون کردن مخزن**:
   ```bash
   git clone https://github.com/Hosein-rad/fitshow-demo/
   ```
2. باز کردن فایل index.html در مرورگر (نیاز به سرور خاصی نیست – HTML خالص).

3. برای مشاهده صفحات دیگر، از منوی ناوبری استفاده کنید یا مستقیماً فایل‌های about.html و contact.html را باز کنید.

---


## 🛠️ تکنولوژی‌های استفاده شده

- **HTML5**
- **CSS3** (با Flexbox و Grid)
- **Font Awesome 6** (CDN)
- **فونت وزیرمتن** (Vazirmatn – CDN)
- **Google Maps Embed API** (برای نقشه)

---

   ## 🧩 سفارشی‌سازی سریع

### تغییر رنگ اصلی (قرمز)
در فایل `styles.css`، مقدار `#f44336` را جستجو کنید و با رنگ دلخواه جایگزین کنید.  
مثال: `#00acc1` (فیروزه‌ای)

### تغییر اطلاعات تماس
در `contact.html`، بخش "اطلاعات تماس" را ویرایش کنید (آدرس، تلفن، ایمیل، ساعت کاری).

### جایگزینی نقشه
در `contact.html`، مقدار `src` داخل `<iframe>` را با آدرس گوگل مپ شعبه خود عوض کنید.

### افزودن تصاویر واقعی به تیم مربیان
در `about.html`، هر `.team-img` را به این شکل تغییر دهید:
```html
<div class="team-img">
  <img src="path/to/coach-photo.jpg" alt="نام مربی">
</div>
```
